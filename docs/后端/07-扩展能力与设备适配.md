# 07｜扩展能力与设备适配

## 状态

- 文档状态：初始规划
- 真实 MCP、插件、Tool 和设备调用：未接入
- 当前限制：不声明已经支持任何具体品牌或第三方能力

## 扩展能力分类

### MCP

连接外部数据或服务，管理连接状态、适用范围和调用记录。规划示例包括月历、数据库、文件和搜索。

### Skill

保存固定任务流程和触发条件。Skill 描述流程，不自动获得执行权限。

### 插件

管理安装、版本、启停和依赖。插件市场和商业分成不属于第一版。

### Tool

执行单项能力并记录结果，例如发送消息、读取文件、执行命令或控制设备。建议使用和实际执行必须分开。

## 能力管理原则

- 每项能力有明确来源、版本、状态和适用范围。
- 高频能力可提高推荐优先级。
- 长期不用的能力可以降低优先级，但不自动删除。
- 系统可根据当前任务和已授权范围推荐能力。
- 实际执行始终遵循权限档位、风险确认和调用记录要求。
- 停用或撤销后不得继续调用。

## 设备适配层目标

前端只展示统一设备中心；平台后端通过适配器把不同品牌命令转换为统一动作，例如：

- 读取状态
- 开启
- 关闭
- 设置模式
- 读取关键参数
- 立即停止

具体品牌协议和命令格式不在初始规划文档中确定。

## 设备类别与边界

| 类别 | 可能能力 | 主要约束 |
| --- | --- | --- |
| 手机 | 通知、文件、剪贴板、打开 App、定位、相机、麦克风 | 依赖系统权限或伴侣服务 |
| 家电 | 空调、扫地机器人、洗衣机等 | 优先官方接口或用户本地网关 |
| 穿戴设备 | 运动、睡眠、心率和提醒 | 健康数据按高敏感数据处理 |
| 摄像头与门锁 | 状态、截图、告警和门禁 | 单独日志、立即撤销和高风险确认 |
| 亲密设备 | 连接、模式、强度和远程控制 | 明确同意、立即停止、禁止默认后台控制 |

## 第一版接入策略

- 先定义统一设备接口。
- 只选择一个可测试适配器完成闭环。
- 未连接的品牌显示“添加适配器”或“连接服务”。
- 不一次接完小米、美的、Apple 等全部品牌。
- 不用模拟状态假装真实设备已经受控。

## 调用与设备日志

每次真实调用后续至少需要关联：

- 用户和主体
- 能力或设备
- 动作和范围
- 权限结果
- 调用时间
- 执行结果摘要
- 是否属于高风险操作

秘密参数、密钥和不必要的敏感原文不进入普通日志。

## 第一版验收方向

- 至少一个 MCP 或 Tool 完成真实、可验证、可撤销的调用闭环。
- 至少一种设备可以安全读取或控制。
- 推荐能力不会绕过执行权限。
- 危险设备提供立即停止和撤销入口。
- 未接入的品牌不会被标记为已支持。
