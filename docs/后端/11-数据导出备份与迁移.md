# 11｜数据导出、备份与迁移

## 状态

- 文档状态：初始规划
- 实现状态：未完成
- 当前限制：不指定导出文件格式细节、备份介质或迁移工具

## 目标

让用户能够理解、保存、恢复、删除和迁移与自己及其智能体有关的数据，并在未来更换设备、模型或载体时保留经历、状态和数据关系。

## 可导出范围

- 主体状态
- 原始软件事件
- 消息隐藏版本和重置记录
- 窗口摘要
- 完整对话
- AI 私域数据和开放记录
- 权限与访问记录
- 模型、工具和扩展配置状态
- 设备与授权数据
- 月历、管账、体重和本地记忆等生活模块数据

密钥、密码和不能安全迁移的秘密凭据不应以明文导出。

## 导出形式

规划至少提供：

- 人类可读格式
- 机器可迁移格式

导出内容应尽量保留时间、来源、版本、主体归属和数据关系。具体格式等待实现阶段确认。

## 导出范围选择

- 全量导出
- 按模块导出
- 脱敏导出
- 是否包含隐藏消息版本和重置记录

用户需要明确知道导出包含什么，以及哪些内容因安全原因被排除或脱敏。

## 备份与恢复

- 数据库需要支持备份和恢复。
- 恢复后仍需保持用户、主体、来源、时间和版本关系。
- 恢复操作需要形成数据变化事件和受控记录。
- 恢复不能把一个用户的数据写入另一个用户或主体。
- 具体备份周期和恢复目标等待部署规划确定。

## 删除与保留

- 支持删除账号。
- 支持删除单个智能体主体。
- 支持删除单条或单类生活、记忆和私域数据。
- 隐藏版本和审计记录仍受用户权利、保留周期和法律要求约束。
- 删除结果需要明确区分立即不可见、等待清理和依法保留等状态；具体规则等待正式隐私政策确定。

## 未来载体迁移

未来接入仿真机器人、实体设备或其他 AI 平台时，迁移对象不只是聊天文本，还包括：

- 主体经历
- 当前状态
- 时间关系
- 记忆来源
- 事件与版本关系
- 权限与可见性信息

本文件不定义具体机器人、设备或第三方 AI 平台协议。

## 运行数据边界

- 运行数据不得自动写入 GitHub。
- 数据恢复不得修改项目仓库代码。
- API Key 和设备凭据不进入普通导出包。
- 管理者后台只能在授权范围内查看用户、状态、事件、错误和使用日志。

## 第一版验收方向

- 用户可以导出自身和指定主体的数据。
- 导出结果能表达来源、时间、版本和关系。
- 脱敏导出不会包含秘密值。
- 备份恢复不破坏用户和主体隔离。
- 删除账号和删除主体的范围清晰且可验证。
