## 总体开发顺序

总规划给出的阶段顺序如下：

| 阶段 | 主要任务 | 完成标准 |
| --- | --- | --- |
| 0. 整理现状 | 冻结核心代码、修正文档、确认测试 | 知道已有内容，不重复建设 |
| 1. 产品蓝图 | 明确核心页面与流程 | 页面和按钮流程明确 |
| 2. 后端数据设计 | 用户、主体、事件、消息版本、记忆、权限、设备和私域 | 每类数据知道存在哪里 |
| 3. 平台后端 | 登录、数据库、事件总线、模型路由和密钥管理 | 手机前端可以安全调用 |
| 4. 前端第一版 | 完成核心页面和手机布局 | 一个用户可以完整使用 |
| 5. 接入连续性引擎 | 状态、事件、摘要、跨窗口和重置版本 | 连续性真实生效 |
| 6. 扩展能力 | 至少一个 MCP 或 Tool | 完成一次真实调用闭环 |
| 7. 设备中心 | 统一接口和一个设备适配器 | 至少一种设备可安全读取或控制 |
| 8. AI 私域 | 申请、开放、拒绝和删除 | 规则真实可用 |
| 9. 生活模块 | 月历、管账或体重先完成一个闭环 | 数据与 AI 互动可用 |
| 10. 公开测试 | 用户隔离、备份、监控、隐私和安全 | 少量用户不会串数据 |
| 11. 开源发布 | 许可证、贡献指南、部署和安全说明 | 其他人可以部署、理解和贡献 |

## 第一版必须完成

- 账号、数据库和用户/主体隔离
- 软件事件总线
- 消息版本、删除、分支和重置记录
- 上下文摘要、跨窗口和本地记忆基础
- 模型/API 路由基础和手动选择
- 权限五档、撤销和访问日志
- AI 私域基础和数据导出
- 至少一个 MCP 或 Tool

## 第一版暂缓

- 全品牌家电接入
- 无限后台扫描和无限 Token
- 复杂多用户协作编辑
- 自动永久人格变化
- 完整自动费用优化
- AI 无限制自动执行
- 真实转账、代扣和账户冻结
- 插件商店和商业分成

## 部署与运维准备

总规划要求公开测试前具备：

- 用户和主体隔离
- 数据库备份和恢复
- 错误与使用日志
- 运行监控
- 数据导出和删除
- 隐私与安全规则
- 密钥不进入 GitHub

具体部署平台、环境数量、容器、网络和监控产品不在当前规划中确定，等待后端技术栈 ADR。

## 测试范围

### 数据隔离

- 不同用户不能读取或修改彼此数据。
- 同一用户的不同主体不会混用状态、记忆、私域或设备权限。

### 对话与事件

- 编辑、重生成、删除、分支和重置记录关系正确。
- 软件事件不包含秘密原文。
- 窗口重置不自动删除连续状态。

### 权限与安全

- 五档权限行为符合定义。
- 会话授权按时失效。
- 高风险操作需要具体确认。
- 撤销权限后调用停止。

### 模型与扩展

- 模型切换不影响主体状态。
- 打开应用不自动消耗 Token。
- 外部能力失败不会被伪造成成功。
- 推荐能力不会绕过执行权限。

### 数据治理

- 导出范围与用户选择一致。
- 备份恢复不破坏隔离关系。
- 删除账号、主体和单项数据的范围清晰。

## 阶段完成原则

- 每一阶段先规划、再实施、再测试、再记录和提交。
- 页面存在不等于后端能力完成。
- 本地 JSON 或模拟数据不等于公开运行数据库。
- 底层连续性原型不等于平台后端完成。
- 未通过安全和隔离测试，不进入公开测试。

## 下一步边界

先审查第一阶段工程设计和阻塞性 ADR 清单。未经新的明确开发任务，不初始化后端运行时、不连接数据库、不接入 API 或模型，也不继续开发其他功能。
