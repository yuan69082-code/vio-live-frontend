# 01｜总体架构与系统边界

## 状态

- 文档状态：持续维护
- 实现状态：基础服务、开发数据库、User/Subject、Dashboard、Conversation/Message/MessageVersion、ConversationSummary、SubjectState、跨窗口摘要、只读 Context 基础 API、Event、Provider/Model Router、Permission 以及 Security/Confirmation/AuditLog 已可运行；前端已建立独立 API 客户端和健康握手，真实认证、页面数据迁移、Memory、真实模型/连续性调用、正式数据库和其他后续平台模块未实现
- 依据：Vio Live 产品与开发总规划 v2.4

## 目标

平台后端为 Vio Live 提供账号、数据、模型、权限、事件、设备和扩展能力的运行基础。即使前端只显示简单页面，后端也应能够保存用户与智能体的归属、重要变化、未完成事项、当前权限和可用能力。

## 五层结构

### 用户端前端

负责页面展示和用户操作，不直接承担数据库、密钥、模型路由、设备适配或审计职责。

当前前端通过独立 `src/api/` 边界和开发期同源代理连接平台后端；页面仍使用原有 mock。连接层建立不等于登录、首次设置或工作台已经使用真实数据。

当前后端对话层保存主体范围的线性文本消息、不可变版本历史、带来源摘要和开发调用方提交的状态版本，并能只读装配跨窗口 Context。保存 `senderType=subject`、重生成版本、摘要或 `state_update` 都不表示真实模型或连续性引擎已经运行；对话页面仍使用 mock。

### 平台后端

负责：

- 账号与身份确认
- 数据库存储与隔离
- 软件事件总线
- 对话版本和隐藏记录
- 模型与 API 路由
- 权限、安全和访问日志
- MCP、Skill、插件和 Tool 管理
- 手机、家电与穿戴设备适配
- AI 私域与生活模块的数据服务
- 数据导出、备份、恢复和迁移

### 连续性引擎

负责身份、关系、时间、意图、情绪、记忆影响、状态演化、学习和资源。平台后端通过稳定接口读取或回写所需状态，不归并其内部逻辑。

### AI 模型

作为可替换的能力提供方。智能体主体状态不能因更换 GPT、Claude、GLM、本地模型或中转服务而丢失。

### 外部能力

包括 MCP、Skill、插件、Tool、手机、家电、穿戴设备和第三方服务。外部能力必须经过平台后端的连接、授权、调用和记录流程。

## 平台后端与相邻系统的边界

| 相邻系统 | 平台后端负责 | 平台后端不负责 |
| --- | --- | --- |
| 前端 | 提供受控数据和操作入口 | 页面布局、动画和视觉主题 |
| 连续性引擎 | 传递主体、上下文、事件和状态更新 | 连续性引擎内部的状态演化算法 |
| AI 模型 | 路由、配置、上下文装配和结果接收 | 模型自身训练与内部推理机制 |
| 外部能力 | 适配、授权、调用和日志 | 假装支持未接入的品牌或服务 |
| GitHub | 保存代码和规划文档 | 保存运行数据、用户数据和密钥 |

## 第一版必须覆盖

- 账号、数据库以及用户和智能体隔离
- 软件事件总线
- 消息编辑、重生成、删除和重置的版本记录
- 上下文摘要、跨窗口和本地记忆基础
- 模型/API 路由基础和手动选择
- 权限五档、撤销和访问日志
- AI 私域基础和数据导出
- 至少一个可验证的 MCP 或 Tool 闭环

## 暂缓范围

- 一次接完全部品牌家电
- 无限后台扫描和无限 Token
- 复杂多用户协作分支编辑
- 完整自主学习与自动永久人格变化
- 大量动画和高级主题市场
- 完整自动费用优化
- AI 无限制自动执行
- 真实转账、代扣和账户冻结
- 插件商店与商业分成

## 完成判断

平台后端完成不能以“已有本地原型”或“前端已有页面”为依据。正式完成至少需要真实账号隔离、数据库、事件、权限、模型路由、密钥保护、错误与访问记录，以及可被手机前端安全调用的稳定接口。
