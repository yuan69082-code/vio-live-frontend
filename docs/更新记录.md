# Vio Live 更新记录

## 0.3.0｜2026-07-22

### 新增

- 新增「前端 3｜主导航框架」。
- 新增工作台、对话、连续性、AI 私域、能力和我的六个底部导航入口。
- 新增六个统一的空白占位页面。
- 新增底部导航本地切换、选中状态和浏览器标题同步。
- 首次设置完成或跳过高级设置后可进入主导航框架。

### 验证

- 通过 TypeScript 与 Vite 生产构建。
- 通过 320px、390px 手机宽度布局检查。
- 六个导航标签均可切换，无文字截断或控件越界。
- 在全新浏览器页面中验证无控制台错误。

### 当前限制

- 六个入口仅包含占位内容，尚未实现具体页面功能。
- 导航状态不会持久化，刷新后仍从登录页开始。
- 未连接后端、数据库或 API。

## 0.2.0｜2026-07-22

### 新增

- 新增「前端 2｜首次设置页面」原型。
- 新增智能体名称和可选头像设置。
- 新增基础定位、记忆保存方式和默认上下文模式选择。
- 新增自定义定位补充输入框。
- 新增“跳过高级设置”和“完成设置”的纯前端交互反馈。
- 登录页完成前端登录流程后可进入首次设置页面。

### 验证

- 通过 TypeScript 与 Vite 生产构建。
- 通过 320px、390px 手机宽度布局检查。
- 页面无控件越界，浏览器控制台无错误。

### 当前限制

- 所有设置只存在于当前页面状态中。
- 未连接后端、数据库或 API。
- 尚未开发首次设置之后的页面。
