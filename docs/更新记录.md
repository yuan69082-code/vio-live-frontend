# Vio Live 更新记录

## 0.21.0｜2026-07-27

### 新增

- 新增 Security Service、规则化风险分类器与统一安全检查接口。
- 新增 SensitiveData 五类分类元数据，所有分类明确禁止接收正文。
- 新增五分钟有效、作用域/策略绑定的 `security_confirmations` 与只追加 `audit_logs` 开发数据库结构、仓储和领域服务。
- 新增敏感分类、安全检查、确认读取/决定和审计只读路由。
- 新增安全风险、三种确认要求、确认隔离/防重放、审计和 `allow_once` 时点测试。

### 调整

- 后端状态进入“平台后端 5｜安全系统基础”，版本更新为 `0.5.0`。
- Permission `allow_once` 增加非消费预览，安全链满足前不会提前消耗。
- Permission 变更和 APIProvider 配置变更新增最小化 AuditLog；原有 Event 仍独立承担软件变化记录。
- SQLite 事务允许内部服务加入同一外层事务，用于权限、确认与审计原子编排。

### 验证

- `pnpm test`：12 项测试通过，0 项失败。
- 验证 `low`、`medium`、`high`、`critical` 风险及免确认、每次确认、用户自定义确认。
- 验证 Permission `ask`/`deny` 联动、高风险长期允许仍需确认，以及确认过期、策略绑定和单次使用。
- 验证安全审计持久化、条件查询、跨用户隔离与 Permission/APIProvider 配置变更记录。
- 前端代码、前端依赖和前端构建配置无修改。

### 当前限制

- 安全检查只返回执行资格并明确标记未执行，不连接真实支付、设备、手机权限或外部能力。
- 本阶段 SensitiveData 没有正文写入接口，AuditLog 没有 payload/正文列；按契约不得把 API Key、身份/支付原文、私密记录正文或 AI 私域正文作为资源引用传入。已有账号邮箱等基础身份字段不属于该分类模块。
- 资源 ID 的常见凭据形态拦截是启发式防线，不是生产级 DLP；真实资源接入仍需可信资源注册表和秘密扫描。
- 真实认证、用户确认偏好存储、可配置确认有效期、加密、生产审计保留和法律策略仍未完成。

- 验证七类资源、跨用户/主体隔离、重启持久化及权限变化事件。
- 前端代码、前端依赖和前端构建配置无修改。

### 当前限制

- 未实现会话级授权、通配范围、继承、优先级、有效期或高风险操作确认。
- 未执行或接入真实 MCP、Skill、Tool、设备、手机权限、AI 私域或连续性引擎。
- 正式数据库、审计保留周期和生产并发策略仍未完成。
