# Vio Live 更新记录

## 0.7.0｜2026-07-23

### 新增

- 新增「前端 7｜AI 私域页面」。
- 新增四项默认锁定的私域目录和申请查看页面。
- 新增申请理由输入、发送申请与内容开放预览。
- 新增全部开放、部分开放、暂时拒绝和延后开放四种预设模拟回复状态。
- 新增申请时间、开放范围与操作记录组成的模拟查看记录。
- 新增 AI 私域页头、目录、申请面板、回复状态、记录与共用图标组件。

### 调整

- 将主导航中的“AI 私域”占位内容替换为 AI 私域页面。
- 能力和我的继续保留原有空白占位内容。
- 目录和申请页面使用本地 React 状态切换，进入新目录项目时重置申请内容与回复状态。

### 验证

- 通过 TypeScript 与 Vite 生产构建。
- 通过 320px、390px 手机宽度布局检查。
- 通过目录锁定、申请理由校验、发送申请和四种预设回复状态检查。
- 全部/部分开放按范围显示模拟内容，拒绝/延后保持锁定；页面无横向溢出或控制台错误。

### 当前限制

- 所有私域条目、开放内容、回复状态和查看记录均为本地模拟数据。
- 申请不会发送、保存或触发真实 AI 判断。
- 未连接后端、数据库或 API。
