- 决定 continuity-engine 是 SubjectState 唯一权威源；Vio 只保存投影、快照、缓存和审计。Vio Event 只变为无状态修改能力的 Observation，由引擎决定是否影响状态。
- 前端只连接 Vio；Vio负责用户数据、权限安全、私域安全存储、Token 和模型/Tool/设备安全通道，引擎负责最终认知 Context、连续性判断和状态演化；数据库不合并。
