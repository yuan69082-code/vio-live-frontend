# 后端测试策略

后端测试将至少覆盖：

- 用户与主体隔离
- 会话、消息版本、分支和重置关系
- 软件事件结构与敏感字段脱敏
- 权限五档、会话失效、撤销和高风险确认
- continuity-engine、模型和外部能力边界
- 导出、删除、备份和恢复范围
- 错误结果不泄露密钥或其他用户数据

当前使用 Node.js 内置测试运行器，不连接任何真实外部服务。测试数据库位于操作系统临时目录，每个测试使用独立 SQLite 文件并在结束后清理。

运行：

```bash
pnpm test
```

当前已覆盖服务启动、User/Subject/Event、Provider/Model/Router、Permission CRUD、五档三态判断、Security 四级风险、三种确认要求、确认隔离与防重放、AuditLog、`allow_once` 确认前预览与最终消费、软删除、权限事件联动、重启持久化、跨用户/主体隔离和密钥字段拦截。所有测试只访问本地测试服务与临时 SQLite，不调用真实模型、支付、设备或外部 API。
