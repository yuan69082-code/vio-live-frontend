# 后端测试策略

后端测试将至少覆盖：

- 用户与主体隔离
- 会话、消息版本、分支和重置关系
- 软件事件结构与敏感字段脱敏
- 权限五档、会话失效、撤销和高风险确认
- continuity-engine、模型和外部能力边界
- 导出、删除、备份和恢复范围
- 错误结果不泄露密钥或其他用户数据

当前使用 Node.js 内置测试运行器，不连接任何真实外部服务。测试数据库位于操作系统临时目录，每个测试使用独立 SQLite 文件并在结束后清理。

运行：

```bash
pnpm test
```

当前已覆盖服务启动与健康检查、用户/主体/事件闭环、Provider 创建查询与状态更新、Model 创建与能力查询、Router 规则选择、数据重启后读取、跨用户隔离，以及事件和 Provider 密钥字段拦截。所有测试只访问本地测试服务与临时 SQLite，不调用真实模型或外部 API。
