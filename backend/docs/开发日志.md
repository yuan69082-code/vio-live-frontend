# Vio Live 后端开发日志

## 2026-07-26｜平台后端 4：权限系统基础

### 当前状态

- 已建立 Permission 数据结构、仓储、CRUD 服务和三态 Permission Checker。
- 权限按用户、主体、资源实例和具体操作精确匹配，没有规则时默认拒绝。
- 权限创建、更新、删除及单次消费会同步创建 `permission_changed` Event。
- 当前只判断权限，不执行 MCP、Skill、Tool、设备、手机权限或 AI 私域操作。

### 已完成内容

- 新增 `004_create_permissions.sql`，建立权限表、复合主体归属外键、当前规则唯一索引和 Checker 查询索引。
- 支持 `memory`、`tool`、`mcp`、`skill`、`device`、`api`、`private_domain` 七类资源。
- 支持 `always_allow`、`ask_every_time`、`allow_once`、`denied`、`forbidden_ask` 五档权限。
- 支持创建、单项/条件查询、更新和软删除；状态包括 `active`、`inactive`、`consumed`、`deleted`。
- Checker 返回 `allow`、`ask` 或 `deny`，并返回是否允许再次询问和命中规则信息。
- `allow_once` 首次判断后原子变为 `consumed`；权限变更与事件同 SQLite 事务提交。
- 后端服务版本更新为 `0.4.0`。

### 测试结果

- `pnpm test`：9 个测试通过，0 个失败。
- Permission 创建、查询、更新、删除、状态筛选和重启持久化通过。
- 五档权限的三态映射、无规则默认拒绝和 `allow_once` 单次消费通过。
- 七类资源、跨用户/主体隔离和非法资源/等级拒绝通过。
- 权限变更 Event 的类型、来源、主体和变更类别通过。
- 原有 User、Subject、Event、Provider、Model、Router 和健康检查测试继续通过。

### 当前限制

- 当前没有会话级权限、通配范围、继承、优先级、有效期或高风险操作确认。
- 当前不执行任何真实资源操作，也不接入手机权限、设备、MCP、Skill、Tool 或 AI 私域。
- 软删除记录和事件的正式保留期限仍待隐私与生产数据库决策。

### 下一步

- 等待权限系统基础审查。
- 未收到新的明确任务前，不开发 MCP、Tool、设备、手机权限、AI 私域或连续性引擎。

## 2026-07-26｜平台后端 3：模型路由与 API 管理基础系统

### 当前状态

- 已建立 APIProvider、Model 和 Model Router 基础模块。
- 已支持 Provider 创建、列表/单项查询和启停状态更新。
- 已支持 Model 创建、单项查询及按 `chat`、`vision`、`image`、`video`、`embedding` 能力查询。
- Router 仅执行本地确定性规则匹配，不连接或调用任何真实模型服务。

### 已完成内容

- 新增 `003_create_api_providers_and_models.sql`，建立 Provider、Model 和能力标签关系表及归属约束。
- Provider 支持 `openai`、`claude`、`glm`、`custom` 四种基础类型和 `enabled`/`disabled` 状态。
- Model 保存 Provider 归属、模型名称、模型类型和去重后的能力标签。
- Router 只在启用 Provider 中匹配任务能力，按稳定创建顺序返回首个模型描述。
- API Key 引用字段只作物理占位并强制为 `NULL`；接口拒绝 Key、Token、Secret 和凭据输入，也拒绝 Base URL 内的凭据信息。
- 后端服务版本更新为 `0.3.0`。

### 测试结果

- `pnpm test`：7 个测试通过，0 个失败。
- Provider 创建、查询、列表、状态更新和重启后持久化通过。
- Model 创建、单项查询、能力查询和能力标签去重通过。
- Router 正确返回能力匹配模型，并在 Provider 停用时排除其模型。
- 跨用户 Provider/Model 访问、非法能力和密钥输入均被拒绝。
- 原有 User、Subject、Event 和健康检查测试继续通过。

### 当前限制

- 没有真实 API Key、密钥库、供应商 SDK、连接测试、模型调用、Token 或费用统计。
- 没有优先级、备用模型、健康探测或自动故障切换；当前只返回首个规则匹配项。
- 没有连续性引擎、权限、MCP、Skill、Tool 或设备实现。

### 下一步

- 等待模型路由基础系统审查。
- 未收到新的明确任务前，不接入真实模型或继续开发权限、MCP、Tool、连续性引擎和设备。
