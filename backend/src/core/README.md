# 共享内核边界

本目录未来只承载跨模块且稳定的后端概念，例如：

- `user_id`、`subject_id` 与来源标识
- 时间、版本、可见范围和数据状态
- 通用错误与操作结果语义
- 权限判断所需的公共契约
- 不依赖供应商实现的事件头部
- 跨 Vio 模块复用的 RFC 8785 canonical JSON 与 SHA-256

共享内核不得包含数据库客户端、HTTP 请求对象、模型 SDK 或设备厂商协议。当前实现包括应用错误、UUID 生成、输入校验，以及不依赖外部运行时适配器的 canonical JSON/哈希工具；Continuity Integration 继续从同一实现重导出旧入口以保持 V1—V5 兼容。
